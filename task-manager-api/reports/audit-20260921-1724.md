### [HIGH] Unsafe Handling of Credentials and Sensitive Data   (AP-08)   F-11

### [HIGH] Unsafe Handling of Credentials and Sensitive Data   (AP-08)   F-12
File: models/user.py:27-32
Description: Passwords are hashed with unsalted MD5 (`hashlib.md5(pwd.encode()).hexdigest()`) and verified with a plain `==` comparison.
Impact: A single database or API read (F-11) exposes hashes that fall to precomputed tables in seconds, compromising accounts here and anywhere the password is reused.
Recommendation: Use a salted, iterated password KDF from the standard library (PBKDF2-HMAC-SHA256) with a constant-time comparison, verifying legacy MD5 hashes once and re-hashing them on successful login; see RP-08.
Contract: safe (login semantics unchanged; the hash string format is internal)
